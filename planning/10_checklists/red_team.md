# Adversarial Red Team

## Claim attacks

- “This is a classifier dressed up as research.”
- “Your pilot participants were told which error to make.”
- “The language signal is overclaiming.”
- “A rule can overfit the observed worksheet.”
- “You leaked the held-out answer.”
- “Your confidence percentages are arbitrary.”
- “This is still grading.”

For each attack, the repository and video must contain a visible defense, not only a verbal answer.

## Product attacks

- Upload a bad page.
- Correct OCR to a different answer and verify posterior refresh.
- Create a pattern that collides between two rules.
- Create inconsistent responses and verify no-consistent behavior.
- Remove network access and run Judge Mode.
- Ask for a new-pattern proposal that attempts code injection.

## Visual attacks

- Can a judge understand the class map in three seconds?
- Does the most impressive screen contain evidence or decoration?
- Is any critical text smaller than video captions?
- Are four or more panels competing for attention?
- Does the UI look like a template used by dozens of AI submissions?

## Pitch attacks

- Mute the video: is the story still clear?
- Watch only the first 30 seconds: is the problem and product clear?
- Skip the voiceover: does the prediction reveal prove reality?
- Ask what the teacher does Monday: is the answer on screen?
