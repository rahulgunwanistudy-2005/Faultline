# First-Place Gate

## Product

- [ ] One-sentence problem is visible above the fold.
- [ ] Seeded upload-to-class-map flow works without a model key.
- [ ] Class groups correspond to different teacher actions.
- [ ] Every diagnosis has item-level evidence.
- [ ] Ambiguous state refuses to guess.
- [ ] Held-out prediction appears before reveal.
- [ ] Tomorrow card contains exactly three high-value questions.

## AI credibility

- [ ] Vision model only transcribes.
- [ ] Posterior includes OCR uncertainty.
- [ ] Information gain is computed, not described vaguely.
- [ ] Novel rule path uses restricted DSL and verifier.
- [ ] No arbitrary generated code is executed.
- [ ] Evaluation numbers have dataset labels.

## Technical

- [ ] Core test suite passes independently.
- [ ] Full lint/type/test suite passes.
- [ ] Upload errors and model timeouts have usable states.
- [ ] All clicks work.
- [ ] Demo deployment works in incognito.
- [ ] No secrets or student data are committed/logged.

## Visual

- [ ] No generic purple gradient or chatbot shell.
- [ ] No cramped dashboard.
- [ ] Main text is legible in 1080p recording.
- [ ] Motion is purposeful and reduced-motion safe.
- [ ] Screenshots are coherent and brand-consistent.

## Submission

- [ ] Video is below two minutes.
- [ ] Captions are accurate.
- [ ] GitHub and live links are public.
- [ ] README includes setup, architecture, evaluation and limitations.
- [ ] Devpost copy has no unsupported improvement claim.
