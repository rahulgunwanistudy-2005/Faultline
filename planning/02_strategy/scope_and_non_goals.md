# Scope and Non-Goals

## Winning scope

### Subject

Adding fractions with unlike denominators, with matched bare-computation and word-problem items.

### Supported input

- One class set of 8–15 pages for the polished demo.
- One worksheet template with fixed problem regions.
- Photo/PDF upload and a stylus/manual-entry fallback.
- Intermediate work lines where available.

### Supported outputs

- class groups by best-supported procedure;
- item-level evidence and posterior distribution;
- held-out prediction;
- next three diagnostic questions by information gain;
- transparent action: re-explain, practice, or inspect wording/context;
- insufficient-evidence state.

## Non-goals for the submission

- automatic grading or report-card integration;
- all fraction operations;
- open-ended geometry or algebra recognition;
- longitudinal mastery tracking;
- causal learning-effect estimates;
- automatic parent communication;
- autonomous teaching decisions;
- storing identifiable student records;
- natural-language generation of arbitrary executable code.

## Why narrow wins

A narrow domain permits:

- executable rules rather than vague labels;
- exhaustive unit tests;
- a clean controlled pilot;
- a deterministic held-out reveal;
- a flawless two-minute story;
- defensible answers to technical judges.

Breadth can be a roadmap slide. Depth must be in the demo.
