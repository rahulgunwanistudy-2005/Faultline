# Video Shot List

## Recording requirements

- 1920×1080, 30 fps.
- Browser zoom chosen before recording; no tiny text.
- Use seeded demo data and a clean incognito session.
- Hide bookmarks, extensions, notifications, API keys and local paths.
- Add burned-in captions only after final voice timing is locked.
- Use light cursor highlighting; no frantic movement.

## Shots

1. Teacher quote and stack — 10s
2. Landing/upload — 12s
3. Extraction and confidence review — 17s
4. Class map — 15s
5. Diego evidence and held-out reveal — 22s
6. Ambiguous case and information gain — 16s
7. Evidence Lab — 13s
8. Tomorrow card and close — 13s

## Editing rule

Use hard cuts or one subtle paper-slide transition. Avoid cinematic intros, long logo reveals, stock footage, or architecture diagrams in the main two minutes.

## Thumbnail

Create a high-contrast thumbnail with:

- left: student work crop;
- center: “3/10” prediction;
- right: matching held-out answer;
- title: **“The wrong procedure beneath the score.”**
