# Execution Priority

The official deadline is explicit and has no extension. Even though the long-term build plan is comprehensive, prioritize by submission value.

## Tier 0 — cannot submit without these

1. Public repository and README.
2. Deployed app or locally recorded working prototype.
3. Two-minute video under the cap.
4. Core malrule engine with unit tests.
5. Seeded demo class and held-out prediction reveal.
6. Class map + evidence drawer + tomorrow card.

## Tier 1 — major scoring multipliers

1. Featherless vision extraction with OCR review.
2. Confidence gating and ambiguous-case flow.
3. Controlled-pilot confusion matrix.
4. Judge Mode.
5. Clean visual design and mobile-safe video framing.

## Tier 2 — only after Tier 0 and Tier 1 are stable

1. Novel-malrule synthesis.
2. Background worker and persistent job queue.
3. Authentication and class history.
4. Multiple worksheet templates.
5. Full observability dashboard.

## Safe submission tactic

Create the Devpost submission early with a provisional video and repository, then improve it before the safe cutoff. Never let final polish prevent a valid submission.
