# Rubric-Critical Test Cases

## Educational impact

- A class with three distinct patterns produces three different action lanes.
- A student with matched bare/word split gets cautious wording, not an identity claim.
- A teacher can export or copy the tomorrow card in one action.

## AI/ML

- OCR candidate uncertainty changes the posterior.
- Two hypotheses that match the same observed answers remain near-tied.
- A candidate item where those hypotheses disagree ranks above one where they agree.
- A novel proposal cannot survive without executable reproduction.

## Technical

- Corrupt upload returns a useful error.
- External model timeout enters review mode.
- Held-out answer is absent from diagnosis request and logs.
- Demo mode works with no API key.
- All buttons and links are interactive or visibly disabled with explanation.

## Pitch

- Judge Mode restarts and pauses.
- Captions remain legible at 1080p video compression.
- Prediction is displayed before reveal.
- Evaluation numbers have dataset labels on screen.
