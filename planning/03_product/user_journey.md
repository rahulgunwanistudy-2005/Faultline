# User Journey

## Screen 1 — “What are they actually doing?”

A quiet landing panel with two actions:

- **Run the 30-second judge tour**
- **Analyze a worksheet stack**

Below it, one proof sentence: “Not a grade. A procedure-level explanation with evidence.”

## Screen 2 — Upload and review

The worksheet stack appears as paper thumbnails. The right panel shows extraction progress:

1. Pages found
2. Problems found
3. Work read
4. Procedures tested

Only low-confidence readings interrupt the flow. The correction UI is large and fast: crop on the left, structured fraction input on the right.

## Screen 3 — Class map

The primary result is not a table. It is three visually distinct lanes:

- **Re-explain the idea**
- **Practice the procedure**
- **Check the wording**

Each lane contains student chips and one plain-English procedure summary. A fourth “Need more evidence” lane appears only when needed.

## Screen 4 — Student evidence drawer

Clicking a student opens a side drawer, preserving the class context. It shows:

- top hypotheses and posterior bars;
- a compact item matrix: problem, observed answer, predicted answer, match;
- intermediate-step clues;
- the recommended action and why.

## Screen 5 — Prediction reveal

A prominent “Test this diagnosis” control shows a new problem and Faultline’s predicted response. The answer remains hidden until the teacher clicks “Reveal held-out work.” The reveal animates the real page next to the prediction.

## Screen 6 — Tomorrow card

For ambiguous students, the system produces three printable questions with a four-minute estimate and a simple explanation: “Question 2 separates ‘add across’ from ‘keep the first denominator.’”

## Screen 7 — Evidence Lab

A judge-facing but teacher-readable panel shows:

- evaluation dataset type;
- OCR accuracy;
- engine accuracy on exact transcriptions;
- end-to-end controlled-pilot confusion matrix;
- model/provider and deterministic verifier status;
- explicit limitations.

This screen is a credibility multiplier and should not dominate the normal teacher flow.
